Pictures uploaded by a manager through admin_manage.php land in this folder.

The database stores only the FILE NAME (project brief, Task 1), and every
name generated by handle_upload() begins with "upload_" so the application
knows to look here rather than in images/cars/.

This folder must be writable by the web server. On XAMPP for Windows it
already is. On Linux or macOS run:

    chmod 775 app/images/uploads
